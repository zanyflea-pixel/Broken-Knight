# Filesystem cleanup - 2026-07-29

## Outcome

The project was reduced from roughly 5.5 GB to 0.42 GB while preserving the
playable Godot build, current runtime assets, canonical Blender source files,
project documentation, and supported launchers.

## Removed

- Retired JavaScript/browser prototype and its local server scripts.
- Generated screenshots, captures, review media, logs, downloads, and scratch
  directories.
- Godot editor/import cache and generated QA artifacts.
- One obsolete 114 MB pre-rig hero export and stale backup asset sidecars.
- Blender previews, snapshots, automatic backups, and 190 dated or
  checkpoint-style `.blend` files.
- Unreachable Git objects and stale loose-object garbage.

The Godot cache was rebuilt after cleanup. It is safe to remove again, but the
next editor/game startup will be slower while active assets are reimported.

- Current Blender build/export scripts.
- Design documentation and stable project launchers.
