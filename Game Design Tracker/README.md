# Broken Knight – Game Design Tracker

This folder is the permanent source of truth for requested gameplay and world features. It exists so future work can extend Broken Knight without losing, duplicating, or silently removing earlier ideas.

## Files

- `MASTER-FEATURE-LIST.md` – the complete organized feature inventory and current status.
- `WORLD-EXPANSION-ROADMAP.md` – the scalable region plan and recommended build order.
- `BUG-TEST-CHECKLIST.md` – repeatable in-game checks for regressions and unfinished behavior.

## Status language

- **Implemented** – a working version exists in the project.
- **Partial** – a foundation exists, but the requested quality or depth is not finished.
- **Verify** – code or content exists but needs a focused in-game test.
- **Queued** – requested and deliberately retained for a later pass.

Nothing marked Partial or Queued should be treated as forgotten. When a feature changes, update its status and add a dated note rather than deleting the entry.
