# Broken Knight Godot Project

This directory contains the playable game.

- Project: `project.godot`
- Main scene: `scenes/Main.tscn`
- World configuration: `data/world/profile.json`
- Runtime code: `scripts/`
- Imported source assets: `assets/`
- QA scripts: `tools/`

Use the launchers in the repository root so the correct bundled Godot version
and project path are selected.

See `EDITING-GUIDE.md` to find the correct script for movement, combat, hero
visuals, world generation, UI, inventory, and maps. Run `..\project.bat check`
before saving a Git checkpoint.
