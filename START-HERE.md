# Broken Knight Start Here

This project is organized around three simple entry points.

## Open the game

Use:

- `play-godot-world.bat`

Desktop shortcut:

- `Broken Knight - Play.lnk`

## Open the Godot editor

Use:

- `start-godot.ps1`

Desktop shortcut:

- `Broken Knight - Godot Editor.lnk`

This opens the canonical Godot project at:

- `godot/project.godot`

## Open the hero in Blender

Use:

- `open-hero-blender.bat`

Desktop shortcut:

- `Broken Knight - Hero Blender.lnk`

This opens the canonical hero source:

- `blender/BrokenKnight_Hero_Master.blend`

## Build areas

### World Build

Read first:

- `WORLD-BUILD-START-HERE.md`

World Build owns:

- terrain
- rivers
- roads
- bridges
- towns
- maps
- traversal
- world performance

### Hero Build

Read first:

- `blender/README.md`
- `blender/FILE-INDEX.md`

Hero Build owns:

- hero body
- hero face
- rigged hero source
- armor fit
- hero export pipeline

## Canonical sources

- Game project: `godot/project.godot`
- Main scene: `godot/scenes/Main.tscn`
- World profile: `godot/data/world/profile.json`
- Hero source: `blender/BrokenKnight_Hero_Master.blend`

## Safe rule of thumb

If you are not sure what to open:

1. Open `START-HERE.md`
2. Pick one of the three entry points above
3. Do not use old runner tools unless you specifically mean to work on those tools
